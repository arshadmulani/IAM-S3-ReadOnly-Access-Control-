# IAM-S3-ReadOnly-Access-Control-
This project demonstrates how to control Amazon S3 access using AWS Identity and Access Management (IAM).  An IAM user is added to an IAM group with read-only access to an S3 bucket. The user can view and download objects but cannot upload or delete objects. 
AWS Cloud IAM + S3 Read-Only Access Control project. Configured IAM user/group permissions and tested S3 access: read/download allowed, upload/delete denied.
